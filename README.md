# Banco de dados e SQL — Conserto do Lele

Atividade acadêmica desenvolvida em dupla durante os estudos de Banco de Dados. O exercício simula a estrutura de um negócio de conserto e venda de peças de computador.

## Objetivo

Praticar a criação e consulta de um banco de dados relacional, passando por etapas como:

- criação do banco e das tabelas;
- definição de chaves e relacionamento entre tabelas;
- inserção de registros;
- consultas com `SELECT`;
- filtros e consultas com `INNER JOIN`;
- criação e controle de permissões de usuário.

## Arquivos

- [consertodolele.sql](./consertodolele.sql) — script com a estrutura, os dados e as consultas da atividade;
- [Atividade 2 - SQL.pdf](./Atividade%202%20%20-SQL.pdf) — material da atividade acadêmica.

## Como utilizar

1. Instale um sistema gerenciador de banco de dados compatível com o script.
2. Abra o arquivo `consertodolele.sql`.
3. Execute os comandos por etapas, conferindo a criação das tabelas, os registros e o retorno das consultas.
4. Leia os comentários e comandos do script para acompanhar o raciocínio da atividade.
